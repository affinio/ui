# @affino/treeview-laravel

Livewire hydration helpers for `@affino/treeview-core`.

The bridge renders tree role/item attributes and observes structural input attributes during Livewire morphs. It preserves active, selected, and expanded state while an owning root remains connected; permanent root removal releases its owned lifecycle state.

## Scripts

```bash
pnpm --filter @affino/treeview-laravel build
pnpm --filter @affino/treeview-laravel test
```
